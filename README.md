# [B42] 集成汉化补全

Project Zomboid B42 集成简体中文翻译模组，版本 1.1.1，包含 10,751 条翻译，面向原版及其他模组中的相关文本。本次控制台兼容性检查使用游戏 42.22.2（revision `3d39148846`）；其他版本与模组组合以实际情况为准。

1.1.1 对照当前来源脚本，为 90 个服装盒物品的 ItemName key 补齐 `Base.` 模块名。当前游戏的 JSON 加载与查找接口可查回 10,749 条；既有的 `Entity_Open_Window` 和 `IGUI-HSGF42.ui` 不受当前 getText 路由支持，仍不生效。真实客户端与完整第三方模组组合未验证。

将本仓库内容放入 `Zomboid/mods/CN_Integrated_Translation/`，使 `mod.info` 和 `42.21/` 位于该目录下，然后在游戏中启用。排序放在被翻译的模组和其他汉化包之后。

本项目是纯翻译资源。模组列表标题、硬编码文本和部分 Java 界面不能通过这些翻译文件覆盖。
